# Bengali AI Response Evaluation

## About This Project

This project demonstrates a basic framework for evaluating
AI-generated responses in Bengali.

The project focuses on:

- Accuracy
- Relevance
- Bengali grammar
- Overall response quality

## Evaluation Method

Each AI response is evaluated using a 1–5 scoring system.

## Dataset

The dataset contains sample Bengali questions and
AI-generated responses with evaluation scores.

## Skills Demonstrated

- AI Response Evaluation
- Data Annotation
- Bengali Language Evaluation
- Data Quality Assessment
- Analytical Thinking

## Purpose

This is a portfolio project demonstrating my interest
in AI data annotation and LLM evaluation.
