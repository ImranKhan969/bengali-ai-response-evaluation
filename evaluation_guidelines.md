# Evaluation Guidelines

## Purpose

This document provides guidelines for evaluating the quality, accuracy, and consistency of completed tasks.

## General Evaluation Criteria

Each submission should be evaluated based on the following criteria:

### 1. Accuracy
- The response should correctly identify and describe the required information.
- There should be no major factual errors.
- The output should follow the task instructions.

### 2. Completeness
- All required parts of the task should be completed.
- Important information should not be missing.
- The response should address all relevant requirements.

### 3. Relevance
- The answer should directly address the task.
- Unnecessary or unrelated information should be avoided.

### 4. Clarity
- The response should be easy to understand.
- Information should be organized logically.
- Language should be clear and appropriate.

### 5. Consistency
- Similar cases should be evaluated using the same standards.
- The evaluator should apply the guidelines consistently.

## Rating Scale

### Excellent
The submission is accurate, complete, relevant, clear, and fully follows the instructions.

### Good
The submission is generally correct and complete but contains minor issues that do not significantly affect the result.

### Fair
The submission meets some requirements but contains noticeable errors, omissions, or clarity issues.

### Poor
The submission has significant errors, missing information, or does not adequately follow the instructions.

## Evaluation Process

1. Read the task instructions carefully.
2. Review the complete submission.
3. Check accuracy and completeness.
4. Identify any errors or missing information.
5. Assign an appropriate rating.
6. Provide a concise explanation for the rating.

## Important Notes

- Do not evaluate based on personal preference.
- Follow the task-specific instructions whenever they are provided.
- When uncertain, review the instructions before making a final evaluation.
- Evaluations should be objective, consistent, and evidence-based.
